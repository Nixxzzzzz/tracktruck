# AURELIS FLEET — Android Driver Field Terminal (`/apps/mobile`)

## Overview
This directory is reserved for the Flutter Android Driver Application.

## Architectural Notes
- **Framework**: Flutter 3.22+, Dart 3.4+.
- **Offline Engine**: Drift (SQLite) with local outbox queue and background retry worker.
- **Ergonomics**: High-contrast, tactile oversized touch targets designed for minimal friction in vehicle cabins.

*Implementation scheduled for Phase 6 & 7 (Android Driver App & Offline Sync).*
