# AURELIS FLEET — Web Operations Console (`/apps/web`)

## Overview
This directory is reserved for the Next.js 14 Web Command Center serving Super Admins, Admins, Fleet Managers, and Depot Supervisors.

## Architectural Notes
- **Framework**: Next.js 14+ (App Router), React 18, TypeScript 5.
- **Design System**: Tailored Luxury Dark Mode (`#0B0C0E` background, `#C8A96B` warm champagne gold accents, automotive telemetry aesthetic).
- **Communication**: Consumes backend REST API at `/api/v1/`.

*Implementation scheduled for Phase 5 (Web Operations).*
